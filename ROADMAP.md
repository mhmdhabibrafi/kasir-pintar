# Roadmap KASPINDO

Dokumen ini menjelaskan rencana pengembangan KASPINDO dalam beberapa tahap ke depan. Roadmap bersifat tentatif dan dapat berubah sesuai masukan komunitas dan kebutuhan pengguna.

## Versi 1.x (Stabil)

- Pembuatan dokumentasi lengkap (README, CONTRIBUTING, SECURITY, dll).
- Penambahan screenshot dan video demo di dokumentasi.
- Rilis v1.0 dengan fitur kasir dasar, shift, inventori, loyalitas, refund, laporan, dan notifikasi.
- Implementasi backup otomatis dan perbaikan bug dasar.
- Penyiapan contoh data (seed) untuk demo aplikasi.
- Penggunaan lisensi open-source (MIT License).

## Versi 2.x (Peningkatan Fitur)

- Penambahan modul multi-user dengan peran (kasir, admin, pemilik toko).
- Integrasi pembayaran digital (QRIS, e-wallet) secara opsional.
- Dukungan barcode scanner perangkat keras.
- Modul manajemen pelanggan dengan histori pembelian.
- Dashboard analitik penjualan lebih lengkap dengan grafik.
- Peningkatan keamanan (CSRF, XSS, SQL injection) dan audit trail.
- Dukungan Docker untuk deployment lebih mudah.

## Versi 3.x (Ekspansi & AI)

- Integrasi modul AI untuk rekomendasi produk dan prediksi stok.
- Sinkronisasi dengan marketplace (Tokopedia, Shopee) untuk impor/ekspor pesanan.
- Modul mobile app (Flutter/React Native) untuk kasir dan monitoring.
- Internationalization (i18n) untuk bahasa Inggris dan lainnya.
- Plugin atau integrasi ke akuntansi pihak ketiga.
- Peningkatan performa untuk instalasi skala menengah ke atas.

Silakan ajukan issue atau pull request jika Anda memiliki ide atau ingin berkontribusi terhadap roadmap ini.
