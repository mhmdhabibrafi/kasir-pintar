# Contributing to KASPINDO

Terima kasih atas minat Anda untuk berkontribusi pada proyek ini. Kami menerima kontribusi berupa perbaikan bug, penambahan fitur, perbaikan dokumentasi, dan lain-lain. Silakan baca panduan berikut sebelum berkontribusi.

## Cara Berkontribusi

1. Fork repo ini dan clone ke lingkungan lokal Anda.
2. Buat branch baru dari `main` untuk perubahan Anda.
3. Pastikan commit Anda deskriptif dan ringkas.
4. Buat pull request dan jelaskan perubahan Anda secara rinci.
5. Tanggapi masukan dari maintainer dengan sopan.

## Standar Kode

- Ikuti standar coding PHP/Laravel yang ada.
- Tambahkan dokumentasi dan unit test jika diperlukan.
- Hindari commit yang tidak terkait dengan perubahan Anda.

## Dukungan

Jika Anda memiliki pertanyaan, buka issue baru di repository ini. Kami akan berusaha merespons secepat mungkin.
