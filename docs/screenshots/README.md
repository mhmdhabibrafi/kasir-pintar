# Direktori Screenshot

Direktori ini berisi gambar screenshot atau tangkapan layar untuk dokumentasi KASPINDO. Silakan tambahkan file gambar (.png/.jpg) ke dalam folder ini sesuai kebutuhan, misalnya `dashboard.png`, `kasir.png`, `laporan.png`, dan lainnya.

Jika Anda menambahkan screenshot baru, pastikan untuk mereferensikannya di README atau dokumentasi terkait. Jangan menyimpan file sensitif atau informasi pribadi di sini.
